🚀 NEON DEFENDER: SETOR OMEGA

Jogo arcade Twin-Stick Space Shooter / Roguelite 360° desenvolvido integralmente em HTML5 Canvas, CSS3 e JavaScript puro (Vanilla JS), sem dependências externas ou motores de jogos.

🎮 Funcionalidades Principais

Combate Espacial 360°: Movimentação omnidirecional, mira livre com cursor do mouse e suporte completo a telas sensíveis ao toque (joysticks virtuais duplos).

Campanha de 5 Fases com Setores Randomizados: Cada fase sorteia um setor espacial único com modificadores ambientais (Nebulosa Azul, Tempestade Iônica, Vazio Gravitacional, Nebulosa Carmesim e Cinturão de Asteroides).

4 Chefões Exclusivos:

Guardião Ômega: Barragens em espiral e rajadas direcionadas.

Hidra Prisma: Feixes laser giratórios com telégrafo visual e invocação de drones.

Colosso Bélico: Mísseis teleguiados destrutíveis e ondas de choque expansivas.

Núcleo Soberano (Fase 5): Chefe final multi-fase que combina múltiplas mecânicas.

Progressão Roguelite & Zona Segura (Hangar):
  Cartas de melhorias táticas em combate com escalonamento progressivo de pontuação.
  Hangar Intergaláctico entre fases para reparar o casco, comprar upgrades permanentes e desbloquear 5 skins exclusivas de nave.
  Áudio Procedural: Efeitos sonoros sintetizados em tempo real via Web Audio API (sem necessidade de arquivos .mp3 externos).

🕹️ Controles:
Tecla / Ação               
 W,A,S,D ou Setas para Movimentar a nave na arena 360°

Mouse para Rotacionar a nave e mirar

Clique Esquerdo ou Espaço para Disparar canhões

F para Alternar disparo automático (Auto-Fire)

1, 2, 3 para Selecionar carta de buff durante o combate

ESC ou P para Pausar / Retomar a partida
